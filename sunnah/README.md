# 5 весомых сунн

Трекер пяти сунн: каждый день отмечаете галочки, по итогам месяца получаете рейтинг-цвет.

1. Пост по понедельникам и четвергам (в остальные дни пункт неактивен и не влияет на рейтинг)
2. Ночной тахаджуд-намаз
3. Чтение Корана после фаджр-намаза
4. Духа-намаз
5. Садака — 10% дохода (+ калькулятор доли за месяц)

## Рейтинг месяца

`выполнено / возможно` за дни месяца от первой отметки по сегодняшний день:

| Доля       | Цвет            |
|------------|-----------------|
| более 75%  | ярко-зелёный    |
| более 50%  | зелёный темнее  |
| более 25%  | ещё темнее      |
| до 25%     | чёрный          |

## Доказательства

Вкладка «Доказательства» — аяты (арабский текст + смысловой перевод) и хадисы с источниками для каждой сунны. У каждого пункта на главном экране есть ссылка прямо на свой раздел, а внизу — «напоминание дня», которое каждый день меняется.

## Запуск

Это обычная веб-страница без сервера и без ключей. Данные хранятся в браузере устройства (`localStorage`); перенос на другой телефон — через «Резервную копию» на вкладке «Месяц».

- Локально: `npx serve sunnah` или `python3 -m http.server -d sunnah` и откройте адрес в браузере.
- На телефон: разместите папку на любом статическом хостинге с HTTPS (GitHub Pages, Netlify, Cloudflare Pages), откройте и выберите «Добавить на главный экран» — приложение будет работать офлайн.
