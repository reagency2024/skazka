# 5 весомых сунн

Трекер пяти сунн: каждый день отмечаете галочки, по итогам месяца получаете рейтинг‑цвет.

1. Пост по понедельникам и четвергам (в остальные дни пункт неактивен и не влияет на рейтинг)
2. Ночной тахаджуд‑намаз
3. Чтение Корана после фаджр‑намаза
4. Духа‑намаз
5. Садака — 10% дохода (+ калькулятор доли за месяц)

## Что умеет

| Вкладка | Что там |
|---|---|
| **Сегодня** | Пять галочек, переход к прошлым дням, **уважительная причина** (болезнь, в пути, хайд, другое), напоминание дня из Корана и Сунны |
| **Месяц** | Рейтинг‑цвет, разбивка по суннам, календарь, лента года, расчёт садаки 10% |
| **Группы** | Общий рейтинг с семьёй и друзьями по коду приглашения |
| **Доводы** | Аяты (арабский текст и смысловой перевод) и хадисы с источниками |
| **Ещё** | Напоминания, профиль и синхронизация, резервная копия |

### Рейтинг месяца

Доля = выполнено / возможно за дни месяца от первой отметки по сегодняшний день.

| Доля | Цвет |
|---|---|
| более 75% | ярко‑зелёный |
| более 50% | зелёный темнее |
| более 25% | ещё темнее |
| до 25% | чёрный |

В день с уважительной причиной засчитывается только сделанное, а пропуски не учитываются.

### Напоминания

| Где | Как работают |
|---|---|
| Android‑приложение | Уведомления ставит само приложение, интернет не нужен |
| Браузер или установленная веб‑версия (с сервером) | Push‑уведомления присылает сервер. На iPhone — iOS 16.4+ и приложение добавлено на экран «Домой» |
| Где угодно, без сервера | Кнопка «Добавить в календарь телефона» скачивает `.ics`‑файл с повторяющимися событиями |

Варианты: тахаджуд, Коран после фаджра, духа (каждый день), «завтра пост» (вечером в воскресенье и среду), «отметить день» (каждый вечер, сервер добавляет счёт дня).

### Синхронизация и группы

- **Профиль** создаётся по имени, пароль не нужен. Приложение выдаёт **ключ синхронизации**: введите его на другом телефоне, и отметки сольются. При конфликте побеждает более поздняя правка по каждому дню.
- **Группа** создаётся в один шаг, вступают по 6‑символьному коду. Участники видят только имя, процент и цвет месяца друг друга. Отдельные отметки и суммы садаки не показываются никому.

Без сервера всё, кроме групп и push‑уведомлений, работает офлайн на одном устройстве.

## Запуск сервера

Нужен Node.js 22+.

```bash
cd sunnah
npm install
npm start              # http://localhost:8080
```

Сервер раздаёт само приложение и API. Данные лежат в одном файле `data/sunnah-db.json`: его достаточно регулярно копировать для бэкапа.

### Размещение в интернете

Телефонам нужен адрес с **HTTPS**. Подойдёт любой хостинг Node.js или Docker **с постоянным диском**: VPS, Railway, Fly.io, Render (платный тариф с диском).

```bash
docker build -t sunnah5 sunnah
docker run -d -p 8080:8080 -v sunnah5-data:/data --restart unless-stopped sunnah5
```

| Переменная | Значение |
|---|---|
| `PORT` | порт, по умолчанию 8080 |
| `DATA_DIR` | папка с базой; в Docker — `/data` |
| `VAPID_SUBJECT` | контакт для push‑служб: `mailto:вы@почта.ru` или адрес сайта |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | необязательно; без них ключи создаются при первом запуске и хранятся в базе |

После запуска откройте адрес сервера на телефоне. Синхронизация, группы и push включатся сами.

## Android‑приложение

**Готовый APK.** Его собирает GitHub Actions при каждом изменении папки `sunnah/`: вкладка **Actions** → «sunnah-android» → последний запуск → **Artifacts** → `sunnah5-android`. Распакуйте и установите `app-debug.apk` (телефон попросит разрешить установку из этого источника).

Чтобы приложение сразу знало адрес вашего сервера, задайте в репозитории переменную `SUNNAH_SERVER` (Settings → Secrets and variables → Actions → Variables), например `https://sunnah.example.com`. Без неё адрес можно ввести в приложении: «Ещё» → «Адрес сервера».

**Собрать самому** (нужен Android Studio):

```bash
cd sunnah
npm install
SUNNAH_SERVER=https://sunnah.example.com npm run android
npx cap open android        # дальше Run ▶ или Build → Generate Signed APK
```

Для Google Play нужна подписанная release‑сборка (Build → Generate Signed Bundle) и аккаунт разработчика.

## iPhone

- **Без App Store.** Откройте адрес сервера в Safari → «Поделиться» → «На экран Домой». Приложение работает офлайн, push‑напоминания приходят на iOS 16.4+.
- **Нативное приложение.** Нужен Mac с Xcode и аккаунт Apple Developer:

  ```bash
  cd sunnah
  npm install
  npm run ios
  npx cap open ios          # в Xcode: Signing → ваша команда, затем Run ▶
  ```

## Устройство

```
sunnah/
  public/          приложение (работает и само по себе, и внутри Android/iOS-обёртки)
    core.js        общая логика: рейтинг, уважительные причины, слияние данных, напоминания
    proofs.js      аяты и хадисы
    app.js         интерфейс
    sw.js          офлайн-режим и приём push
  server.mjs       сервер: синхронизация, группы, push (зависимость — только web-push)
  native/          иконки, заставка и донастройка Android-проекта
  test/            тесты: npm test
```
