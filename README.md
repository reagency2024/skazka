# Сказка про меня 🌙

Веб‑приложение для родителей: персональная сказка на ночь, где главный герой — ваш ребёнок.

## Как это работает

| Шаг | Что происходит | Сервис |
|---|---|---|
| 1. **Фото** | Родитель загружает фото, указывает имя и возраст. Claude по фото коротко описывает внешность героя для художника (описание можно поправить). | Claude (vision) |
| 2. **Придумать сказку** | Родитель описывает задачу («сказка на 10 минут, где Лола гуляет по парку, а пёс Артемон оберегает её от дворняжек»). Текст печатается в реальном времени. Можно попросить правки, вернуть предыдущий вариант, поправить вручную. Кнопка **УТВЕРЖДЁН**. | Claude |
| 3. **Рисунки** | Выбор художника (Recraft или GPT Image) и стиля. Claude делит сказку на сцены, генерируются скетчи раскадровки. Каждый кадр можно перерисовать с правкой. Кнопка «Раскадровка утверждена». | Claude + Recraft / GPT Image |
| 4. **Озвучить** | Голос сказочника из ElevenLabs (с прослушиванием образцов), бесплатный голос устройства или «прочитаю сама». | ElevenLabs |
| 5. **Книга** | Claude раскладывает сказку по страницам и подбирает к ним иллюстрации; по желанию иллюстрации перерисовываются начисто в высоком качестве; сказочник озвучивает каждую страницу. Получается книга с обложкой, посвящением и концовкой: листать, слушать с автоперелистыванием, печатать или сохранять в PDF. | Claude + ElevenLabs |

Все книги лежат на «Полке» на главной странице.

## Запуск

Нужен Node.js 20+.

**Windows:** дважды щёлкните `start.bat` — он установит зависимости, запустит сервер и откроет браузер. Окно с сервером не закрывайте, пока пользуетесь приложением.

Вручную:

```bash
npm install
cp .env.example .env   # впишите ключи
npm start              # http://localhost:3000
```

Ключи (`.env`):

- `ANTHROPIC_API_KEY` — Claude (по умолчанию `claude-opus-5-5`, меняется через `CLAUDE_MODEL`).
- `RECRAFT_API_KEY` и/или `OPENAI_API_KEY` — иллюстрации. В GPT Image фото ребёнка передаётся как образец, поэтому герой получается похожим; в Recraft герой рисуется по текстовому описанию внешности.
- `ELEVENLABS_API_KEY` — озвучка (модель `eleven_multilingual_v2`, хорошо читает по‑русски).

**Без ключей приложение работает в демо‑режиме**: демо‑сказка, картинки‑заглушки, голос браузера. Так можно пройти весь путь до подключения сервисов. Каждый сервис включается независимо от остальных.

## Устройство

```
server.js          Express: API, хранение проектов, сборка книги в фоне
lib/claude.js      описание героя, сочинение и правки (стриминг), раскадровка, вёрстка книги
lib/images.js      Recraft / OpenAI GPT Image, стили рисунков
lib/voice.js       ElevenLabs: список голосов, синтез речи
lib/demo.js        заглушки для демо-режима
public/            интерфейс (чистый HTML/CSS/JS, без сборки)
data/projects/     проекты: project.json, фото, иллюстрации, mp3
```

Ключи API хранятся только на сервере и в браузер не попадают. Фото ребёнка хранится локально в `data/projects/<id>/` и удаляется вместе с проектом.

## Что сделать перед публикацией

- Авторизация пользователей (сейчас все проекты видны всем, кто открыл приложение).
- Хранение файлов в облаке (S3 и т.п.) вместо локального диска.
- Лимиты и оплата: книга с 6–8 чистовыми иллюстрациями и озвучкой расходует платные запросы к нескольким API.
